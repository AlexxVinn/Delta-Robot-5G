# Delta-Robot-5G

High-speed, vision-tracked delta robot (pick-and-place) built around an ESP32 step executor with vision + motion planning on a host PC.

**Realistic Phase-1 target:** ~3 g peak acceleration, ±0.2 mm class repeatability, two software modes (Speed / Precise), ~$400 budget. True joint-level closed loop (encoders + FOC) is a Phase-2 upgrade.
